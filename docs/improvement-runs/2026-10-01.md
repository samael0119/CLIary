## 改动与收益

- 无历史数据时，以三步可操作指引替代零值卡片和重复空面板：启用采集、打开新终端、运行外部工具后刷新。

- 说明扫描与采集是两件事；只保存工具名、时间和本机标识，不保存参数，不导入既有 Shell 历史。

- 中英双语复用一个指引组件；已有记录的历史排行榜和统计图表保持正常。
- README 补充与页面一致的使用步骤。
