## 改动与收益

- CLI 与 Web 均按所选工具的特性键并集生成矩阵，区分 `true`（支持）、`false`（不支持）、缺失（未记录）。常见键使用共享中英文标签，新特性键自动显示，避免硬编码只有磁盘工具的一张表。
- Web 仅在同一特性存在显式 `true` 与 `false` 时标注“存在差异”；有些工具没记录该字段不构成不支持的证据。没有任何特性记录时明确显示未记录。
- 复用 Catalog 的用途描述、命令示例、安装包与仓库信息，不新增未经核实的性能、版本或功能事实。说明特性来源及快照边界，示例只展示，不执行。
- 用途说明与特性排到 Web 表格前部；维度使用行表头，工具使用列表头。四列可直接阅读，更多列在可聚焦表格内横向滚动，维度列固定；差异除底色外还有文字标记。
- CLI 保留简短字段的比较矩阵，将较长的包名、仓库地址、描述和示例放到对应工具的说明区，避免长值挤乱相邻列。
- 未扫描时不再暗示工具未安装，扫描后状态基于快照显示已安装／未检测到。
- 按 Catalog ID 去重，别名不会产生重复列；仍要求输入 2–8 个名称、至少两个不同工具。Web 对未知名称、重复工具、单个工具和数量超限给出可恢复提示，保留输入和推荐组合。数据库失败仍走原有服务错误路径。
- 比较 JSON 原有字段保留，新增 `description` 与 `common_commands`，保持布尔特性与缺失键的原始意义。新增字段反序列化提供默认值。
- 比较页与测试移到独立 `comparison.rs`，减少主 Web 模块中的页面逻辑。README 补充使用方法与数据含义。
