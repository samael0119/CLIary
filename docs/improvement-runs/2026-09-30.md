## 选择的问题与收益

本地工具扫描已支持 PATH，却未读取开发语言的环境变量。仅配置 SDK 或包管理器目录、未加入 PATH 的工具会被遗漏。本轮补上这个可独立验证的识别缺口；按用户反馈扩展到常见语言生态，未局限于 Java 和 Go。

- 新增 JAVA_HOME/bin、GOROOT/bin、GOBIN 和各 GOPATH/bin 扫描。
- GOPATH 未设置或为空时，扫描默认的 ~/go/bin。
- 扩展 Rust、Python（venv、Conda、pyenv、pipx）、Node.js（npm、nvm、Volta、pnpm）、Bun、Deno、Ruby（RubyGems、rbenv）、PHP Composer、.NET 和 asdf 的环境目录及常见用户目录；pnpm 同时覆盖根目录和新版 bin 目录。
- 保留 PATH 的同名工具优先级，去重目录并忽略空环境变量。
- 仅识别可执行文件；目录发现不执行工具，不扫描不存在的目录，不递归遍历项目或全部 SDK 版本。包清单查询仍使用已有的包管理器命令。
- README 说明变量名称、扫描范围和重新扫描方式。
