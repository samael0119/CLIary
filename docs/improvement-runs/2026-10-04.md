## 收益与关键改动

1. Core 新增 `Wrapped` 报告及 `Cliary::wrapped(year)`，提供总调用量、活跃天数、工具数、首末记录、Top 10 工具和十二个月的调用量。默认当前本地年份，显式年份范围为 1–9998，拒绝越界和溢出输入。
2. 时间范围为本地日历年 `[1 月 1 日, 次年 1 月 1 日)`，沿用已有本地年界计算。已记录的同一工具 ID 的可执行别名合并计数，未知工具保留，并列按名称稳定排序。
3. 三次聚合查询使用同一个只读事务快照，避免 Shell 后台追加记录时各部分数字不一致；利用已有时间索引，不读取每条事件到内存、不按工具逐一查询 Catalog。输出结果规模限制为 10 个工具与 12 个月。
4. CLI 新增 `cliary wrapped [year]`，支持中英文和 `--json`。明确当前年尚未结束、统计仅包含已采集调用、空记录无法推断没有使用。
5. Web 新增 `/wrapped`、年份选择表单和侧栏「年度报告 / Wrapped」入口。提供真实数据、空年度、非法年份的可恢复页面；错误年份返回 HTTP 400，表单可修正重试。空状态说明如何启用未来采集、打开新终端，以及不会导入过去命令。
6. 年报延续现有桌面应用壳、绿色配色、明暗主题、圆角面板、字体和焦点样式；汇总以定义列表展示，月度数据使用有行列标题的表格，装饰条隐藏于辅助技术。长名称换行，动态文本转义。年报静态条使用 `transform: scaleX`，未添加宽度动画。只覆盖年报表单按钮的通用样式，改善白色文字对比度。
7. README 增加试用方式、数据口径和仍未完成的能力。没有数据库迁移、模型依赖或联网数据来源；不修改已有使用事件，不自动启用采集。

## 使用与剩余范围

```sh
cargo build -p cliary-cli
./target/debug/cliary wrapped
./target/debug/cliary --lang zh-CN wrapped 2024
./target/debug/cliary wrapped 2024 --json
./target/debug/cliary web
```

网页选择侧栏「年度报告」，或打开 `http://127.0.0.1:8848/wrapped?year=2024`。
