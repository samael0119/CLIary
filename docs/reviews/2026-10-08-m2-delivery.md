## 试用

以下为 Zsh 示例，文件路径应替换为实际历史文件；Bash／Fish 分别使用对应 `--shell`。

```sh
./target/debug/cliary import-history --shell zsh --file "$HISTFILE"
./target/debug/cliary import-history --shell zsh --file "$HISTFILE" --apply
./target/debug/cliary history --undated
./target/debug/cliary wrapped 2024
./target/debug/cliary wrapped 2024 --output wrapped-2024.html
./target/debug/cliary wrapped 2024 --output wrapped-2024.json --format json
./target/debug/cliary web
```

打开 Web 后选择年度报告，年份与历史实际时间对应。输出文件须为尚不存在的路径。没有可靠时间的旧历史仍可浏览观察结果，但不会被分配到某个年份。

## 已知限制及后续

- Shell 历史可能被清理、合并、遗漏，不能还原所有执行。复杂复合命令保守跳过；未知别名／函数名不猜测实际程序。
- 不保存参数，因此不同快照中的同工具同秒调用可能无法区分，去重可能少计；单份快照内同秒次数保留。导入按当前设备归属，不推断来源设备。
- 无时间戳的历史无法支持年度、月份或首次记录日期。分类采用当前 Catalog，可重叠；报告结果随 Catalog 和当前收藏变化，不是不可变历史快照。
- 数据库升级后旧版二进制不能打开 v2，升级后应使用当前构建；迁移事务覆盖旧记录与收藏保全测试。
- 本地模型摘要、语义搜索、Logo、多级目录尚未实现；本轮完成的是已确认的三个阶段。
- 既有扫描子进程超时与旧页面样式提醒见先前集成报告，未纳入本轮。
